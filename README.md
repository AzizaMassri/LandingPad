---

## 🛠️ The Projects

### 🐍 Python Discord Bots
* **The Core Bot:** Uses a modular cog architecture to run a music player, server moderation tools, a translator, minigames, and an activity rewards bank system.
* **Kingshot Helper:** Built directly into the core bot, featuring full gameplay guides and calculators to min-max the game.
* **Standalone Translator:** I stripped the translation cog directly out of the main multi-cog bot and spun it up as a second, independent translation bot.

### 🐹 Go Translation Bot
* **Standalone Engine:** A completely separate bot engineered specifically for high performance.
* **Presence Tracking:** It checks user presence and automatically translates chat rooms in real-time based on who has been active in the last 3 minutes.
